Platform security

Conventity is built on a shared, hardened backbone. Access to systems is least-privilege by default, and operational data is isolated per platform layer.

Data in transit & at rest

Traffic is encrypted in transit. Sensitive data is protected at rest using industry-standard encryption.

Responsible disclosure

If you believe you have found a security issue, please contact us through the Contact link in the site footer. We appreciate responsible disclosure and will respond promptly.
